# The Biocode Editions

Sleek, modern, mobile-responsive website for TBC micro-franchise builders.

## Pages
- `index.html` — Home / Purpose
- `co-build.html` — CRM (customers + scanees, saves in browser)
- `longevity.html` — 6 product pages
- `product.html` — Individual shareable product page
- `events.html` — What’s On
- `login.html` — Login screen

## How to run locally
Just open `index.html` in any browser. No build step required.

## Deploy to GitHub Pages
1. Create a free GitHub account
2. Create a new public repository
3. Upload all files in this folder
4. Go to Settings → Pages → deploy from main branch
5. Your site will be live at `https://yourusername.github.io/repo-name`

Built with Tailwind CSS (CDN) + vanilla JS. Fully responsive.
